# Security

Found a vulnerability in pperp (the command line or its MCP server) or in the Phoenix Perpetuals API? Email **support@phoenixperpsfunding.com** with what
you found and how to reproduce it, and please do not open a public issue for it. We answer every report.

Never send an API key, a webhook secret or a TradingView link in a report: revoke any that is exposed, from the
dashboard.
